# OrbitWorks — MySQL Relational Database Project

OrbitWorks is a hands-on database project developed using MySQL Workbench to practise relational database design and SQL.

The project models a fictional organization through four interconnected tables: `departments`, `employees`, `projects`, and `employee_projects`. It includes an entity-relationship diagram, sample records, primary and foreign keys, and constraints designed to represent organizational relationships and employee project assignments.

This repository documents my learning process, database design decisions, and ongoing improvements as I strengthen my SQL and database management skills.

## Project Objectives

- Practise creating and managing relational tables using MySQL.
- Understand primary keys, foreign keys, and database constraints.
- Model one-to-many and many-to-many relationships.
- Represent employee assignments and their associated historical information.
- Practise SQL queries against sample organizational data.
